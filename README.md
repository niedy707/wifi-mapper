# 📡 WifiMapper

**Free, open-source WiFi heatmap & survey tool for macOS.**

A professional-grade alternative to NetSpot ($49+) and Ekahau ($3000+).

## Quick Start

```bash
git clone https://github.com/niedy707/wifi-mapper.git
cd wifi-mapper
npm install
node server.js
# Open http://localhost:3333
```
